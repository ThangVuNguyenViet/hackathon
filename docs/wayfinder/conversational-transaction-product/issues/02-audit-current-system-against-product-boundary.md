## Question

Which current KFC capabilities can be reused for a vendor-neutral multi-tenant Conversational Transaction Engine, and which capabilities are demo-specific, single-tenant, fixture-bound, incomplete, or absent?

Audit the current checkout and migrations across identity, session state, interruption, run claiming, idempotency, ordering safety gates, catalog observation and caching, commerce projections, human takeover, outcome evaluation, evidence, persistence, queues, connector seams, channel adapters, monitoring, and tests. Trace every relevant flow end to end, preserve unrelated dirty work, and produce a source-linked gap inventory that distinguishes reusable domain logic from KFC-specific behavior and unverified production assumptions. Do not implement fixes.
